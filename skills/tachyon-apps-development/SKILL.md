# Tachyon Apps Development

This skill applies only to the `quantum-box/tachyon-apps` repository. Do not
apply its code conventions or workflows to other repositories.

## Workflow

1. Read [the repository guide](references/repository-guide.md) before
   non-trivial Tachyon apps work or whenever repository rules are needed.
2. Use the matching Tachyon apps skill by its existing name when the guide
   routes the task to a specialized workflow.
3. Keep this guide and the specialized skills as the source of repository
   guidance. The repository's `AGENTS.md` is only a bootstrap to this skill.

The guide preserves the repo-wide rules and skill routing. Skill descriptions
identify which workflows apply only inside this repository.
